Tracker Enhanced（增強追蹤器）

獨立連線： Tracker Enhanced 使用獨立的專用連線，不會干擾 SillyTavern 的主要連線。
建議： 建立專門用於追蹤器生成的連線設定檔，以確保最佳效能並避免衝突。
注意：即使選擇「與當前相同」也會使用獨立連線，並套用當前設定檔的設定。

建議： 建立專門針對追蹤器生成優化的完成預設。
相容性指示：
• ✅ 相容 - 符合您選擇的設定檔的 API
• ⚠️ 可能有相容性問題 - 請謹慎使用
• ❌ 可能不相容 - API 不同，可能導致錯誤
提示：使用較高的溫度設定以獲得更有創意的追蹤，或使用較低的溫度以獲得穩定的結果。

指定追蹤器應該自動為誰生成：使用者、角色、兩者或無。

指定應該為誰顯示彈出視窗以手動輸入追蹤器資料：使用者、角色、兩者或無。

選擇追蹤器的格式：YAML（建議使用，token 使用量較低）或 JSON（增加 token 數量，但對於表現不佳的模型可能效果更好）。
預設設定

定義生成追蹤器的模板。使用巨集如：
{{trackerSystemPrompt}}、{{characterDescriptions}}、{{trackerExamples}}、{{recentMessages}}、{{currentTracker}}、{{trackerFormat}}、{{trackerFieldPrompt}}。

定義追蹤器生成的系統層級提示詞。使用巨集如：
{{charNames}}、{{defaultTracker}}、{{trackerFormat}}。

設定生成追蹤器的請求提示詞。可用的巨集包括：
{{trackerFieldPrompt}}、{{trackerFormat}}、{{message}}（最後一則訊息）。

當我們將追蹤器區塊注入 SillyTavern 提示詞時，在其前方插入的額外指導。請保持簡潔，並專注於敘事知識界限。

追蹤器中近期訊息的模板。巨集包括：
{{char}}、{{message}}、{{tracker}}、{{#if tracker}}...{{/if}}。

定義追蹤器中角色描述的格式。巨集：
{{char}}、{{charDescription}}。

定義每則訊息顯示的追蹤器預覽的 HTML。使用巨集如：
{{key.subkey}}、{{#join "delimiter" arrayKey}}、{{#foreach objectOrArrayKey itemName}}...{{itemName.subKey}}...{{/foreach}}、{{#if key.subkey}}...{{/if}}。
點擊以根據您的 Prompt Maker 欄位自動生成模板
